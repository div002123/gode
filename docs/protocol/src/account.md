# protocol/src/account.rs

## 文件作用

定义账户相关的枚举类型，特别是计划类型（Plan Type）。

## 主要枚举

### `pub enum PlanType`
- 账户计划类型
- 变体：
  - `Free` (默认): 免费计划
  - `Plus`: Plus 计划
  - `Pro`: Pro 计划
  - `Team`: 团队计划
  - `Business`: 商业计划
  - `Enterprise`: 企业计划
  - `Edu`: 教育计划
  - `Unknown`: 未知计划

## 主要函数和方法

无公共函数。该文件主要定义枚举类型。
