# protocol/src/lib.rs

## 文件作用

Protocol 库的主模块，导出所有公共子模块，包括账户、审批、配置、消息历史、协议定义等。

## 主要模块导出

- `account`: 账户相关
- `conversation_id`: 会话 ID
- `approvals`: 审批机制
- `config_types`: 配置类型
- `custom_prompts`: 自定义提示
- `items`: 消息项
- `message_history`: 消息历史
- `models`: 模型相关类型
- `num_format`: 数字格式化
- `parse_command`: 命令解析
- `plan_tool`: 计划工具
- `protocol`: 核心协议定义
- `user_input`: 用户输入

## 主要函数和方法

无公共函数。该文件作为模块导出入口。
