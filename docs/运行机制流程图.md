## 2. 完整用户交互流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Client as 客户端
    participant ASP as app-server-protocol
    participant Core as codex-core
    participant Model as AI 模型 API
    participant Tools as 工具系统
    participant FS as 文件系统

    User->>Client: 输入请求
    Client->>ASP: JSON-RPC Request
    ASP->>Core: NewConversation / UserTurn

    Core->>Core: 构建 Context + Prompt
    Core->>Model: 流式请求 (SSE)

    loop 流式响应
        Model-->>Core: 内容增量
        Core-->>Client: AgentMessageContentDelta
        Client-->>User: 显示内容
    end

    Model-->>Core: ToolCall (apply_patch)
    Core->>Tools: 执行工具

    alt 需要批准
        Tools-->>Client: ExecApprovalRequest
        Client-->>User: 请求批准
        User->>Client: 批准/拒绝
        Client->>Core: ReviewDecision
    end

    Tools->>FS: 应用补丁
    FS-->>Tools: 成功
    Tools-->>Core: ToolResult

    Core->>Model: 继续对话 (附带结果)
    Model-->>Core: 最终响应
    Core-->>Client: TurnCompleted
    Client-->>User: 完成显示
```

## 4. 工具执行流程

```mermaid
flowchart TD
    Start([AI 请求工具]) --> Parse[解析工具调用]
    Parse --> Route[工具路由]
    Route --> CheckType{工具类型?}

    CheckType -->|内置工具| BuiltIn[内置处理器]
    CheckType -->|MCP 工具| MCP[MCP 客户端]

    BuiltIn --> CheckApproval{需要批准?}
    MCP --> CheckApproval

    CheckApproval -->|是| RequestApproval[请求用户批准]
    CheckApproval -->|否| CheckSandbox{需要沙箱?}

    RequestApproval --> WaitUser[等待用户]
    WaitUser --> UserDecision{用户决策}
    UserDecision -->|批准| CheckSandbox
    UserDecision -->|拒绝| ErrorRejected[返回拒绝]

    CheckSandbox -->|是| ApplySandbox[应用沙箱]
    CheckSandbox -->|否| Execute[执行工具]

    ApplySandbox --> Execute

    Execute --> Success{成功?}
    Success -->|是| FormatResult[格式化结果]
    Success -->|否| ErrorFailed[返回错误]

    FormatResult --> End([返回给 AI])
    ErrorRejected --> End
    ErrorFailed --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style Execute fill:#fff4e1
```

## 5. MCP 集成流程

```mermaid
flowchart TD
    Start([Codex 启动]) --> LoadConfig[加载 MCP 配置]
    LoadConfig --> ForEach[遍历 MCP 服务器]

    ForEach --> CheckTransport{传输类型?}

    CheckTransport -->|子进程| LaunchProcess[启动本地进程]
    CheckTransport -->|HTTP| CheckAuth{需要 OAuth?}

    CheckAuth -->|是| PerformOAuth[执行 OAuth 登录]
    CheckAuth -->|否| ConnectHttp[连接 HTTP 服务器]

    LaunchProcess --> Initialize[初始化协议]
    PerformOAuth --> ConnectHttp
    ConnectHttp --> Initialize

    Initialize --> ListTools[列出工具]
    ListTools --> RegisterTools[注册到工具表]

    RegisterTools --> MoreServers{更多服务器?}
    MoreServers -->|是| ForEach
    MoreServers -->|否| Ready[MCP 就绪]

    Ready --> WaitCall[等待调用]
    WaitCall --> ToolCall{MCP 工具调用?}

    ToolCall -->|是| FindServer[查找服务器]
    ToolCall -->|否| WaitCall

    FindServer --> SendRequest[发送 tools/call]
    SendRequest --> HandleResponse[处理响应]
    HandleResponse --> ReturnResult[返回给 AI]
    ReturnResult --> WaitCall

    style Start fill:#e1f5ff
    style Ready fill:#e1ffe1
```

## 6. 认证流程

```mermaid
flowchart TD
    Start([需要访问令牌]) --> CheckMode{认证模式?}

    CheckMode -->|API Key| ReturnKey[返回 API Key]
    CheckMode -->|OAuth| CheckCache{缓存有效?}
    CheckMode -->|None| ErrorNoAuth[错误: 未认证]

    CheckCache -->|是| ReturnCached[返回缓存令牌]
    CheckCache -->|否| LoadKeyring[从 Keyring 加载]

    LoadKeyring --> CheckExpired{令牌过期?}
    CheckExpired -->|否| ReturnStored[返回存储令牌]
    CheckExpired -->|是| RefreshToken[刷新令牌]

    RefreshToken --> CallOAuth[调用 OAuth API]
    CallOAuth --> Success{成功?}

    Success -->|是| UpdateKeyring[更新 Keyring]
    Success -->|否| ErrorRefresh[刷新失败]

    UpdateKeyring --> UpdateCache[更新缓存]
    UpdateCache --> ReturnNew[返回新令牌]

    ReturnKey --> End([使用令牌])
    ReturnCached --> End
    ReturnStored --> End
    ReturnNew --> End
    ErrorNoAuth --> End
    ErrorRefresh --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
```

## 7. 文件搜索流程

```mermaid
flowchart TD
    Start([file-search 调用]) --> ParsePattern[解析搜索模式]
    ParsePattern --> InitWalker[初始化文件遍历器]
    InitWalker --> LoadGitignore[加载 .gitignore]

    LoadGitignore --> StartThreads[启动并行线程]
    StartThreads --> TraverseDir[遍历目录树]

    TraverseDir --> CheckFile{文件匹配?}
    CheckFile -->|否| NextFile[下一个文件]
    CheckFile -->|是| CalcScore[计算匹配分数]

    CalcScore --> AddToList[加入 BestMatchesList]
    AddToList --> CheckLimit{达到限制?}

    CheckLimit -->|否| NextFile
    CheckLimit -->|是| StopSearch[停止搜索]

    NextFile --> MoreFiles{更多文件?}
    MoreFiles -->|是| TraverseDir
    MoreFiles -->|否| Collect[收集所有线程结果]

    Collect --> Sort[按分数排序]
    StopSearch --> Sort

    Sort --> FormatResult[格式化为 JSON]
    FormatResult --> End([返回结果])

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
```

## 8. 补丁应用流程

```mermaid
flowchart TD
    Start([AI 生成补丁]) --> ParseCommand[解析 apply_patch 命令]
    ParseCommand --> ExtractPatch[提取补丁内容]
    ExtractPatch --> ParseHunks[解析补丁块 hunks]

    ParseHunks --> ValidateFiles[验证目标文件]
    ValidateFiles --> AllExist{所有文件存在?}

    AllExist -->|否| ErrorMissing[错误: 文件不存在]
    AllExist -->|是| MatchHunks[匹配补丁位置]

    MatchHunks --> FindContext[查找上下文行]
    FindContext --> FuzzyMatch{精确匹配?}

    FuzzyMatch -->|否| TryFuzzy[尝试模糊匹配]
    FuzzyMatch -->|是| ApplyChanges[应用变更]

    TryFuzzy --> FoundMatch{找到匹配?}
    FoundMatch -->|否| ErrorConflict[错误: 冲突]
    FoundMatch -->|是| ApplyChanges

    ApplyChanges --> GenerateDiff[生成 diff]
    GenerateDiff --> WriteFiles[写入文件]

    WriteFiles --> CreateBackup[创建备份]
    CreateBackup --> RecordChanges[记录文件变更]
    RecordChanges --> End([返回 ApplyPatchAction])

    ErrorMissing --> End
    ErrorConflict --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style WriteFiles fill:#fff4e1
```
