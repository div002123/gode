## 使用说明

### 查看流程图

这些文档使用 Mermaid 语法编写流程图。您可以通过以下方式查看：

1. **GitHub**: 直接在 GitHub 上查看，Mermaid 图表会自动渲染
2. **VS Code**: 安装 "Markdown Preview Mermaid Support" 扩展
3. **在线工具**: 使用 [Mermaid Live Editor](https://mermaid.live/)

### 文档结构

每个流程图文档通常包含：

1. **概述**: Crate 的简要介绍
2. **主流程图**: 展示核心功能的执行流程
3. **子流程图**: 详细展示特定功能模块
4. **数据流图**: 展示数据在各组件间的流动
5. **状态转换图**: 展示状态变化
6. **关键决策点**: 列出重要的分支决策
7. **特殊说明**: 性能优化、安全特性等

## 技术栈

这些 crate 使用的主要技术：

- **语言**: Rust
- **异步运行时**: Tokio
- **序列化**: Serde, serde_json
- **网络**: reqwest, hyper
- **并发**: rayon, tokio (async/await)
- **跨平台**: 条件编译，平台特定实现
- **安全**: Windows 安全 API，系统密钥环
