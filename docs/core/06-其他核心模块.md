# 其他核心模块文档

## exec.rs - 命令执行

### 文件作用
实现命令执行的核心逻辑，提供统一的接口来执行 Shell 命令、处理输入输出流、管理沙箱。

### 主要结构体
- `ExecToolCallOutput`: 执行结果输出
- `SandboxType`: 沙箱类型（None、Seatbelt、Landlock、WindowsSandbox）
- `StreamOutput`: 流式输出捕获

### 主要函数
- `exec()`: 执行命令主入口
- `exec_with_sandbox()`: 带沙箱的命令执行
- `capture_output()`: 捕获命令输出

---

## error.rs - 错误类型

### 文件作用
定义 Codex 系统的所有错误类型，提供统一的错误处理机制。

### 主要枚举
```rust
pub enum CodexErr {
    InternalAgentDied,
    SessionConfiguredNotFirstEvent,
    TurnAborted(TurnAbortReason),
    ToolExecutionFailed(String),
    ModelRequestFailed(String),
    ConnectionFailed(ConnectionFailedError),
    RefreshTokenFailed(RefreshTokenFailedError),
    UsageLimitReached(UsageLimitReachedError),
    SandboxError(SandboxErr),
    // ... 更多错误类型
}
```

### 特性
- 使用 `thiserror` crate 自动生成错误实现
- 提供详细的错误消息
- 支持错误链追踪
- 区分可恢复和不可恢复错误

---

## parse_command.rs - 命令解析

### 文件作用
解析用户输入的命令和消息，识别特殊指令（如 /compact、/undo 等）。

### 主要功能
- 解析斜杠命令（/command）
- 提取命令参数
- 验证命令格式
- 支持命令别名

### 主要函数
- `parse_command()`: 解析命令主函数
- `is_command()`: 判断是否为命令
- `extract_args()`: 提取参数

## git_info.rs - Git 信息

### 文件作用
提取当前工作目录的 Git 仓库信息，包括分支、状态、提交历史等。

### 主要结构体
```rust
pub struct GitInfo {
    pub branch: Option<String>,
    pub status: String,
    pub recent_commits: Vec<String>,
    pub is_repo: bool,
}
```

### 主要函数
- `get_git_info()`: 获取完整 Git 信息
- `get_current_branch()`: 获取当前分支
- `get_git_status()`: 获取工作目录状态
- `get_recent_commits()`: 获取最近提交

## context_manager/ - 上下文管理

### 模块作用
管理对话上下文，包括消息历史、token 计数、上下文截断和规范化。

### 主要文件

#### mod.rs
- `ContextManager`: 上下文管理器主结构
- `add_message()`: 添加消息到历史
- `get_messages()`: 获取消息列表
- `truncate()`: 截断超长上下文

#### history.rs
- 消息历史存储
- 历史记录持久化

#### truncate.rs
- 智能上下文截断
- 保留关键消息
- 计算 token 使用

#### normalize.rs
- 消息格式规范化
- 清理和验证消息
