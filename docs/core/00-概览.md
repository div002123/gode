# codex-core 概览

## 项目简介

`codex-core` 是 Codex 项目的核心库，提供了 AI 代码助手的主要功能实现。这是一个基于 Rust 的异步框架，负责处理与 AI 模型的交互、工具执行、会话管理等核心功能。

## 整体架构

codex-core 采用分层架构设计：

```
┌─────────────────────────────────────────┐
│         会话管理层                        │
│  (ConversationManager, Codex)          │
└─────────────────────────────────────────┘
           │
┌─────────────────────────────────────────┐
│          客户端层                         │
│    (ModelClient, 认证管理)               │
└─────────────────────────────────────────┘
           │
┌─────────────────────────────────────────┐
│         工具编排层                        │
│  (ToolOrchestrator, ToolRegistry)      │
└─────────────────────────────────────────┘
           │
┌─────────────────────────────────────────┐
│        执行和运行时层                      │
│  (Shell, UnifiedExec, MCP)             │
└─────────────────────────────────────────┘
```

## 核心模块

### 1. 会话管理 (Session Management)
- **conversation_manager.rs** - 对话管理器，负责创建和维护对话
- **codex.rs** - 核心 Codex 引擎，处理交互逻辑
- **codex_conversation.rs** - 对话抽象层
- **state/** - 会话、轮次和服务状态管理

### 2. 客户端和通信 (Client & Communication)
- **client.rs** - ModelClient，与 AI 模型 API 通信
- **client_common.rs** - 客户端公共类型和工具
- **chat_completions.rs** - 聊天完成 API 的流式处理
- **auth.rs** - 身份验证和令牌管理

### 3. 工具系统 (Tool System)
- **tools/orchestrator.rs** - 工具编排器，协调工具执行
- **tools/registry.rs** - 工具注册表
- **tools/handlers/** - 各种工具处理器（Shell、文件操作、MCP等）
- **tools/runtimes/** - 工具运行时实现

### 4. 执行环境 (Execution)
- **exec.rs** - 命令执行核心逻辑
- **unified_exec/** - 统一执行框架
- **shell.rs** - Shell 集成
- **bash.rs** - Bash 命令处理

### 5. MCP 集成 (Model Context Protocol)
- **mcp_connection_manager.rs** - MCP 连接管理
- **mcp_tool_call.rs** - MCP 工具调用
- **mcp/** - MCP 相关功能模块

### 6. 配置和上下文 (Configuration & Context)
- **config/** - 配置管理（类型、编辑、配置文件）
- **config_loader/** - 配置加载器
- **context_manager/** - 上下文管理（历史、截断、规范化）
- **environment_context.rs** - 环境上下文信息

### 7. 安全和沙箱 (Security & Sandboxing)
- **sandboxing/** - 沙箱评估和策略
- **command_safety/** - 命令安全检查
- **seatbelt.rs** - macOS Seatbelt 集成
- **landlock.rs** - Linux Landlock 集成
- **safety.rs** - 平台安全抽象

### 8. 任务系统 (Task System)
- **tasks/** - 各种任务类型（紧凑、审查、撤销等）
- **turn_diff_tracker.rs** - 轮次差异追踪

### 9. 辅助功能 (Utilities)
- **error.rs** - 错误类型定义
- **parse_command.rs** - 命令解析
- **git_info.rs** - Git 信息提取
- **project_doc.rs** - 项目文档和用户指令
- **token_data.rs** - Token 数据管理
- **util.rs** - 通用工具函数

## 主要数据流

1. **用户提交** → ConversationManager → Codex
2. **Codex** → ModelClient → AI API
3. **AI 响应** → ResponseProcessing → ToolOrchestrator
4. **工具执行** → ToolHandlers → Shell/UnifiedExec/MCP
5. **执行结果** → Codex → 用户

## 关键特性

- ✅ 异步流式 AI 交互
- ✅ 多种工具支持（Shell、文件操作、MCP）
- ✅ 会话持久化和恢复
- ✅ 多平台沙箱支持
- ✅ 命令安全检查
- ✅ 上下文管理和截断
- ✅ 并行工具执行
- ✅ OAuth 和 API Key 认证
- ✅ 模型提供商抽象

## 依赖关系

核心依赖：
- `tokio` - 异步运行时
- `reqwest` - HTTP 客户端
- `serde`/`serde_json` - 序列化
- `codex-protocol` - 协议定义
- `mcp-types` - MCP 类型
- 各种 `codex-*` workspace crates
