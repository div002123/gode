
## 3. 会话生命周期

```mermaid
stateDiagram-v2
    [*] --> Initializing: spawn()

    Initializing --> Configured: SessionConfigured
    Configured --> Idle: 等待提交

    ProcessingTurn --> StreamingResponse: 调用 AI
    StreamingResponse --> ExecutingTools: 收到工具调用
    ExecutingTools --> WaitingApproval: 需要批准
    WaitingApproval --> ExecutingTools: 用户批准
    WaitingApproval --> Idle: 用户拒绝
    ExecutingTools --> StreamingResponse: 继续对话
    StreamingResponse --> Idle: 轮次完成

    Idle --> Compacting: 上下文太大
    Compacting --> Idle: 压缩完成

    Idle --> Shutdown: 关闭请求
    Shutdown --> [*]

    ProcessingTurn --> Idle: 用户中止
```

## 4. 工具执行流程

```mermaid
flowchart TD
    Start([AI 请求工具调用]) --> Parse[解析工具调用]
    Parse --> Route[ToolRouter 路由]
    Route --> FindHandler{查找处理器}

    FindHandler -->|找到| CheckPolicy[检查批准策略]
    FindHandler -->|未找到| ErrorNotFound[返回 ToolNotFound]

    CheckPolicy --> NeedApproval{需要批准?}
    NeedApproval -->|是| RequestApproval[发送批准请求]
    NeedApproval -->|否| SelectSandbox[选择沙箱]

    RequestApproval --> WaitUser[等待用户响应]
    WaitUser --> UserDecision{用户决策}
    UserDecision -->|批准| SelectSandbox
    UserDecision -->|拒绝| ErrorRejected[返回 Rejected]
    UserDecision -->|中止| ErrorAborted[返回 Aborted]

    SelectSandbox --> ApplySandbox[应用沙箱限制]
    ApplySandbox --> Execute[执行工具]

    Execute --> Success{成功?}
    Success -->|是| CaptureOutput[捕获输出]
    Success -->|否| CheckRetry{可重试?}

    CheckRetry -->|沙箱拒绝| RetryNoSandbox[无沙箱重试]
    CheckRetry -->|其他错误| ErrorFailed[返回 ExecutionFailed]

    RetryNoSandbox --> Execute

    CaptureOutput --> FormatResult[格式化结果]
    FormatResult --> End([返回给 AI])

    ErrorNotFound --> End
    ErrorRejected --> End
    ErrorAborted --> End
    ErrorFailed --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style Execute fill:#fff4e1
    style UserDecision fill:#ffe1e1
```

## 5. 认证和令牌管理

```mermaid
flowchart TD
    Start([需要访问令牌]) --> GetAuth[AuthManager.get_token]
    GetAuth --> CheckMode{认证模式}

    CheckMode -->|API Key| ReturnKey[返回 API Key]
    CheckMode -->|OAuth| CheckToken[检查令牌状态]
    CheckMode -->|None| ErrorNoAuth[错误: 未认证]

    CheckToken --> TokenExpired{令牌过期?}
    TokenExpired -->|否| ReturnToken[返回 access_token]
    TokenExpired -->|是| RefreshToken[刷新令牌]

    RefreshToken --> CallRefreshAPI[POST /oauth/token]
    CallRefreshAPI --> RefreshSuccess{成功?}

    RefreshSuccess -->|是| UpdateStorage[更新存储]
    RefreshSuccess -->|否| CheckError{错误类型}

    CheckError -->|过期/撤销| ErrorPermanent[永久错误: 需要重新登录]
    CheckError -->|网络/临时| ErrorTransient[临时错误: 可重试]

    UpdateStorage --> UpdateMemory[更新内存缓存]
    UpdateMemory --> ReturnNewToken[返回新 token]

    ReturnKey --> End([使用令牌])
    ReturnToken --> End
    ReturnNewToken --> End
    ErrorNoAuth --> End
    ErrorPermanent --> End
    ErrorTransient --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style RefreshToken fill:#fff4e1
    style ErrorPermanent fill:#ffe1e1
```

## 6. 上下文管理和压缩

```mermaid
flowchart TD
    Start([添加新消息]) --> AddMessage[ContextManager.add_message]
    AddMessage --> CountTokens[计算 token 使用]
    CountTokens --> CheckLimit{超过限制?}

    CheckLimit -->|否| UpdateHistory[更新历史]
    CheckLimit -->|是| CheckAuto{自动压缩?}

    CheckAuto -->|是| TriggerCompact[触发压缩任务]
    CheckAuto -->|否| TruncateOld[截断旧消息]

    TriggerCompact --> BuildHistory[构建压缩历史]
    BuildHistory --> CallAI[调用 AI 生成摘要]
    CallAI --> CompactSuccess{成功?}

    CompactSuccess -->|是| ReplaceSummary[用摘要替换历史]
    CompactSuccess -->|否| FallbackTruncate[回退到截断]

    ReplaceSummary --> UpdateHistory
    TruncateOld --> UpdateHistory
    FallbackTruncate --> UpdateHistory

    UpdateHistory --> RecordChange[记录变更]
    RecordChange --> End([继续处理])

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style CallAI fill:#fff4e1
```

## 7. MCP 集成流程

```mermaid
flowchart TD
    Start([Codex 启动]) --> LoadConfig[加载 MCP 配置]
    LoadConfig --> ConnectAll[连接所有 MCP 服务器]

    ConnectAll --> ForEach[遍历服务器配置]
    ForEach --> LaunchServer[启动 MCP 服务器进程]
    LaunchServer --> InitProtocol[初始化 MCP 协议]
    InitProtocol --> ListTools[列出服务器工具]

    ListTools --> RegisterTools[注册到 ToolRegistry]
    RegisterTools --> CheckNext{还有服务器?}
    CheckNext -->|是| ForEach
    CheckNext -->|否| Ready[MCP 就绪]

    Ready --> WaitCall[等待工具调用]
    WaitCall --> ToolCall{MCP 工具调用?}

    ToolCall -->|是| RouteToMCP[路由到 MCP Handler]
    ToolCall -->|否| WaitCall

    RouteToMCP --> FindServer[查找对应服务器]
    FindServer --> SendRequest[发送 tools/call 请求]
    SendRequest --> WaitResponse[等待响应]
    WaitResponse --> HandleResult[处理结果]
    HandleResult --> ReturnToAI[返回给 AI]
    ReturnToAI --> WaitCall

    style Start fill:#e1f5ff
    style Ready fill:#e1ffe1
    style SendRequest fill:#fff4e1
```

## 9. 并发模型

```mermaid
flowchart TD
    Main[主线程/任务] --> SpawnSession[生成 Session 任务]
    SpawnSession --> EventLoop[Session 事件循环]

    EventLoop --> WaitSubmission[等待提交]
    WaitSubmission --> ProcessSubmission[处理提交]

    ProcessSubmission --> StreamTask[创建流任务]
    StreamTask --> |异步| StreamAI[流式请求 AI]

    StreamAI --> ReceiveChunk[接收响应块]
    ReceiveChunk --> SendEvent[发送事件到用户]
    SendEvent --> MoreChunks{更多块?}
    MoreChunks -->|是| ReceiveChunk
    MoreChunks -->|否| ParseTools[解析工具调用]

    ParseTools --> ParallelTools{可并行?}
    ParallelTools -->|是| ForkTasks[Fork 多个任务]
    ParallelTools -->|否| Sequential[顺序执行]

    ForkTasks --> Tool1[工具 1 任务]
    ForkTasks --> Tool2[工具 2 任务]
    ForkTasks --> Tool3[工具 3 任务]

    Tool1 --> Join[Join 所有结果]
    Tool2 --> Join
    Tool3 --> Join
    Sequential --> Join

    Join --> Aggregate[聚合结果]
    Aggregate --> WaitSubmission

    Main --> PollEvents[轮询事件]
    EventLoop --> |发送| EventChannel[事件通道]
    EventChannel --> |接收| PollEvents
    PollEvents --> DisplayToUser[显示给用户]

    style Main fill:#e1f5ff
    style EventLoop fill:#fff4e1
    style ForkTasks fill:#e1ffe1
```

## 10. 错误处理流程

```mermaid
flowchart TD
    Start([操作执行]) --> Try[尝试执行]
    Try --> Success{成功?}

    Success -->|是| ReturnOk[返回 Ok]
    Success -->|否| CatchError[捕获错误]

    CatchError --> ClassifyError{错误分类}

    ClassifyError -->|网络错误| CheckRetry{可重试?}
    ClassifyError -->|认证错误| TryRefresh[尝试刷新令牌]
    ClassifyError -->|工具错误| FormatError[格式化错误消息]
    ClassifyError -->|系统错误| LogError[记录错误日志]

    CheckRetry -->|是| Backoff[指数退避]
    CheckRetry -->|否| ReturnError[返回错误]

    Backoff --> CountAttempts{尝试次数}
    CountAttempts -->|< 3| Try
    CountAttempts -->|>= 3| ReturnError

    TryRefresh --> RefreshSuccess{刷新成功?}
    RefreshSuccess -->|是| Try
    RefreshSuccess -->|否| ReturnError

    FormatError --> SendToAI[发送给 AI]
    SendToAI --> AIHandle[AI 处理错误]
    AIHandle --> End([继续或中止])

    LogError --> SendEvent[发送错误事件]
    SendEvent --> UserDecision{用户决策}
    UserDecision -->|重试| Try
    UserDecision -->|中止| ReturnError

    ReturnOk --> End
    ReturnError --> End

    style Start fill:#e1f5ff
    style End fill:#e1f5ff
    style ReturnError fill:#ffe1e1
    style Backoff fill:#fff4e1
```
